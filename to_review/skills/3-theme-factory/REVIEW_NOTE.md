# Review note — 3-theme-factory

**Priority: 3/4** — The mechanism ux-designer's taste file should copy, with ten worked examples.

*Not in force. This note is a proposal; the verdict is the owner's.*

**Licence: Apache 2.0** — copying and reworking is permitted; attribution and a change notice must travel with any derivative.

## What it is

59 lines plus a themes directory. Ten preset themes, each a palette with hex codes and a font pairing for headings and body, applied to slides, documents or pages. Can generate a new theme on the fly.

## What we already have

`ux-designer` is planned with a `taste.md` that does not exist yet.

## What is worth taking

**The shape, not the themes.** Taste stored as values — `#141413`, 'Poppins for headings' — gets applied consistently; taste stored as prose gets reinterpreted every session. Ten examples of what a complete theme record contains is the template.

## What to leave

The themes themselves. They are somebody else's aesthetic, and the point of `taste.md` is that it is his.
