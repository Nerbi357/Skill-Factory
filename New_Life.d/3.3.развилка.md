# Развилка шага 3.3 · README и философия про одно и то же

Написана рабочим чатом 2026-09-11 до вызова арбитра.

## Вопрос

`README.md` держит таблицу «Что здесь лежит» (строки 78–89), философия держит
таблицу «Вопрос каждого корневого файла» (`PROJECT_PHILOSOPHY_CHECK.md`,
304–314). Три файла — `PROJECT_PHILOSOPHY_CHECK.md`, `PROJECT_MEMORY_CHECK.md`,
`PROJECT_IDEAS_CHECK.md` — описаны в обеих, разными словами об одном и том же.
Что с этим делать.

## Что стоит знать до вариантов

- Таблица README называет семь вещей: три корневых файла, `skills/`, `agents/`,
  `to_review/`, `archive/`. В корне при этом лежат и `SIGNALS.md`, и `LICENSE`,
  и `.claude/`, и `.github/`, и временные `New_Life.md` с `New_Life.d/`. Сам
  шаг 3.3 велит добавить недостающие строки — это часть работы при любом
  варианте, кроме того, где таблица README исчезает.
- Таблица философии называет четыре файла и кончается доводом, зачем их четыре,
  а не один: «каждый меняется в своём ритме».
- Рядом с ней в философии стоит таблица «Связи» (316–324), где уже названы
  `SIGNALS.md`, `bundled/`, `.claude/` и каталог README.
- Принцип библиотеки: философия держит принципы и карту, README — витрину.
- Две редакции одного правила расходятся молча — этим репозиторий уже
  обжёгся, и на такие пары поставлена проверка `check_pairs.py`.

## Варианты

**А. README — плоский список всего, что лежит в корне; объяснение остаётся
философии.** Строка = имя и одна короткая фраза, что это; вопросы «на что
отвечает файл» уходят целиком в философию. В README появляются `SIGNALS.md`,
`.claude/`, `.github/`, `LICENSE`.
*Цена.* Дубль уменьшается, но не исчезает: три файла всё равно названы в обеих
таблицах, просто короче. Посетитель, которому нужно понять разделение труда
между тремя корневыми файлами, идёт в философию.

**Б. Обе таблицы как есть, в README дописать недостающие строки.**
*Цена.* Дубль остаётся полностью и может разойтись молча; чтобы он не разошёлся,
нужна либо пара в `check_pairs.py`, либо дисциплина, которой уже не хватило.

**В. Таблицы в README нет, стоит ссылка на философию.**
*Цена.* Витрина перестаёт отвечать на вопрос «что здесь лежит» сама: первый
пришедший обязан открыть второй файл. README — единственная страница, которую
видит человек, пришедший со стороны.

**Г. Таблицы вопросов в философии нет, стоит ссылка на README.**
*Цена.* Из карты выпадает кусок карты. Философия перестаёт отвечать, зачем
корневых файлов четыре, а не один, — а это принцип, а не витрина.

## Рекомендация рабочего чата

**А.** Довод: дубль здесь — между «что это» и «на какой вопрос отвечает», и по
устройству репозитория второе принадлежит философии, где лежит карта, а первое
— витрине. Вариант А отдаёт каждой таблице её половину и заодно чинит то, что
витрина молчит о четырёх вещах, лежащих в корне.

Слабое место рекомендации, которое вижу сам: полностью дубль не снимается, и
если через месяц строку про память перепишут в одном файле, второй промолчит.
